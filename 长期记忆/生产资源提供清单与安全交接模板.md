# 科瑞特 AI 生产资源提供清单与安全交接模板

> 用途：在生产化开发开始前，由项目负责人和总技术负责人共同确认资源、权限、业务规则与验收数据。  
> 当前已知：阿里云 RDS 已购买，OSS Bucket 已创建。它们仍需补齐连接信息、访问授权、网络策略并完成只显示结果、不回显 Secret 的连通性验证。

## 1. 安全提交方式

### 1.1 Secret 不在对话中发送

以下内容不要粘贴到聊天、Markdown、代码、截图、Git 提交或命令输出中：数据库密码、完整 `DATABASE_URL`、Redis 密码、RAM AccessKey、OSS SecurityToken、MiniMax API Key、Worker Token、管理员密码和服务器私钥。

在应用目录执行一次：

```powershell
Copy-Item -LiteralPath '.env.platform.example' -Destination '.env.production.local'
```

然后只在本机编辑 `.env.production.local`。该文件已由 `.gitignore` 忽略。若应用最终通过 ECS、Docker、CI/CD 或托管平台部署，则把同名变量录入平台的 Secret 管理功能，并在交接时只说明“变量名已配置”，不要提供变量值。

### 1.2 可以在对话或本文件副本中提供的内容

可以提供不含凭据的资源说明、选择和约束，例如：地域、数据库版本、Bucket 名称与地域、是否使用内网、是否启用 TLS、数据是否为空、域名、服务器系统、上线窗口、业务规则、允许使用的测试素材及是否允许创建临时测试账号。

若某项信息不确定，填写“待确认”。总技术负责人必须先提出具体问题并等待项目负责人答复，不得自行猜测。

## 5. 仍需逐项确认的资源

### Redis

生产环境需要 Redis 承担限流、并发和试用状态。请确认使用阿里云 Redis、自建 Redis 或其他兼容服务，并提供网络、TLS、认证和容量信息。若尚未购买，总技术负责人应先给出与当前并发目标匹配的规格建议，待项目负责人确认后再配置。

### MiniMax 与点数规则

请确认已开通的图像、音乐、文本、代码/阅读相关模型，供应商账户可接受的预发布测试成本，以及各工具一次请求需要扣除的站内点数。未经确认，生产开关保持 `AI_GENERATION_ENABLED=false`。

### 服务器、域名和 Worker

请说明应用部署位置、操作系统、Node/Docker 版本、域名解析与 HTTPS 状态，以及是否允许安装 LibreOffice 和 FFmpeg。Worker Token 应使用随机高强度值，仅写入 Secret。

### 测试账号和授权素材

请授权自动创建并清理临时管理员、个人、培训和学校账号，或在 Secret 中配置一次性测试账号。提供的课程、文档、图片、音视频必须允许用于预发布测试，不得包含真实未成年人个人信息。

## 6. 资料齐备确认

总技术负责人完成只读盘点后，应返回一张状态表：`已收到 / 已写入 Secret / 待提供 / 不适用 / 已验证`，列出每项验证方法和阻塞影响。任何字段含义、业务规则、安全选择、成本范围或生产操作不明确时，必须向项目负责人提问并等待回复。

只有项目负责人明确回复下面这句话后，才可修改代码、执行迁移、创建测试数据或操作云资源：

> 资料已齐，可以开工。

这句话只授权按已确认范围开始实施，不自动授权发布到生产、删除生产数据、公开内容、产生未确认费用或向外部人员发送消息；这些动作如未在资料表中明确授权，仍需单独确认。
