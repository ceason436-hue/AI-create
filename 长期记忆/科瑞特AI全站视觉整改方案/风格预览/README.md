## 生成方式

使用 Codex 内置 ImageGen 的 `ui-mockup` 工作流生成 A、B、C 和 D；C 的第二版使用 `precise-object-edit` 仅修复重复 Logo。D 同时引用 A、C 第二版与官方透明 Logo 生成，以 A 为明确视觉母体，只吸收 C 的信息结构。最新 C 精修融合稿使用 `compositing`，以 C 第二版为编辑目标，以 A 为摄影和品牌口号来源。生成提示围绕以下约束编写：浅色导航、单一透明 Logo、两行以内中文标题、主要行动首屏可见、真实图片占主要视觉权重、无三等分圆角卡片、无粗黑描边、无内部技术文案。
