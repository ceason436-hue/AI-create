# 课件私有存储与转换部署清单

> 状态：`[IN_PROGRESS]`  
> 最后更新：2026-09-02  
> 适用应用：`ai音乐/ai-music-app`

本清单记录课程课件上线所需的部署条件。课件原件、预览件和缩略图均不得配置为公网读；浏览器只能访问应用的受鉴权预览接口，不能取得 OSS 长期地址或下载按钮。

## 必要环境变量

- `STORAGE_DRIVER=OSS`
- `OSS_BUCKET`：私有 Bucket 名称。
- `OSS_ENDPOINT`：OSS 区域 Endpoint，可带或不带 `https://`。
- `OSS_ACCESS_KEY_ID`、`OSS_ACCESS_KEY_SECRET`：仅授予该私有 Bucket 所需的读、写、删权限的 RAM 凭据。
- `OSS_SECURITY_TOKEN`：如使用 STS 临时凭据则配置。
- `COURSEWARE_WORKER_TOKEN`：高熵随机值，用于调度器调用处理端点，不能写入前端环境变量。
- `SOFFICE_PATH`：生产环境 LibreOffice/soffice 可执行文件路径；未设置时使用系统 `soffice` 命令。
- `COURSEWARE_UPLOAD_MAX_BYTES`：可选，默认 200 MiB，最大 2 GiB。
- `COURSEWARE_CONVERSION_TIMEOUT_MS`：可选，默认 120 秒，范围 15 秒至 10 分钟。

## 对象分区与访问边界

- 原件：`courseware/original/<courseId>/...`
- 预览件：`courseware/preview/<courseId>/<assetId>/...`
- 学员只可通过 `/api/me/courseware/<assetId>/preview-session` 取得五分钟会话，再由 `/content?session=...` 服务端代理输出预览内容。
- 上传、重试和队列处理仅允许运营管理员，或携带 `COURSEWARE_WORKER_TOKEN` 的服务端调度器。

## 转换调度

课件上传后会生成 `CoursewareJob`。调度器每分钟（或同等可靠的队列消费者）以服务端身份调用：

```text
POST /api/admin/courseware/process-next
Authorization: Bearer <COURSEWARE_WORKER_TOKEN>
```

每次调用安全地领取一个待处理任务：PDF、图片和视频生成私有预览副本；PPT/PPTX 与 Word 使用 LibreOffice 转换为 PDF。失败任务由后台“重新处理”操作重新入队。学员端预览器会使用受保护会话 URL 的 PDF 页码片段实现上一页、下一页、页码缩略导航与全屏展示，不改变原有实时鉴权和动态水印。生产上线前必须用真实 PPT、PPTX、DOC、DOCX、PDF、图片和视频验证字体、分页、宽高比和超时策略。

## 上线验收

部署前先在应用目录运行下列预检；该脚本只输出缺失键名与软件状态，不会输出任何凭据值：

```text
node scripts/courseware-preflight.mjs
```

- 预检必须确认 `storageDriver` 为 `OSS`、`ossConfigured` 与 `libreOffice` 均为 `true`，且 `errors` 为空，再执行数据库迁移、启动调度器与上传真实课件验收。

- Bucket 无匿名公共读，应用服务器以最小 RAM 权限访问。
- 未登录、未报名、报名过期、会话令牌过期均返回拒绝，不输出预览字节。
- 预览接口无下载或长期签名 URL，响应使用 `private, no-store` 和 `inline`。
- PPT/PPTX 预览为 PDF，保持源演示文稿页宽高比；如字体缺失，应先修复转换镜像字体再发布。
- 处理状态为 `READY` 且存在预览件前，后台不能发布课件。
- 处理、上传、发布和学员访问均保留审计记录。
