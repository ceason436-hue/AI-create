## 写入边界

- `package.json`、锁文件、全局 CSS、根/公共布局、导航、页脚、共享设计 token、共享弹窗和中央验收文档只由主 Agent 修改。
- 子 Agent 发现共享需求时只回报接口，不直接修改共享文件。
- 子 Agent 完成后须返回修改文件、实现内容、测试结果、风险与接口变化；主 Agent 检查实际 diff 后再集成。

## 当前依赖顺序

1. 主 Agent 完成共享视觉基础、内容数据接口和公共交互接口。
2. 三个互不重叠的页面批次并行实施。
3. 主 Agent 集成媒体资产、联系弹窗、账户弹窗和首次 AI 使用提示。
4. 全站文案扫描、构建与浏览器四视口回归。
5. 独立 QA 审查提出问题，主 Agent 分派修复并复验。
