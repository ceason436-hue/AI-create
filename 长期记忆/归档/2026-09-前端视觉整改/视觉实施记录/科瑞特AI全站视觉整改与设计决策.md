## 1. 设计判读与整改级别

### 1.1 设计判读

这是一个同时面向在读学员、家长、新学员和学校的青少年科创教育品牌站。公开页面首先承担“理解与信任”，学习中心和 AI 工具承担“完成任务”。整体视觉应像一间真实、有成果、值得信任的当代科创工作室，而不是通用 AI 产品模板或后台系统。

### 1.2 整改级别

采用“视觉世界全面替换，产品事实与既有功能保留”的全站重构方式：

- 保留品牌名称、透明底 Logo、真实课程、真实成果、真实合作资料和既有业务能力。
- 保留现有 URL、权限边界、内容管理与媒体发布能力，除非项目负责人另行确认。
- 现有蓝色、荧光绿、粗黑边、超大标题、圆角卡片堆叠与黑色分割线只作为问题证据，不作为新设计系统的权威。
- `DESIGN.md` 已更新为锁定母版的设计规范。正式实施后只根据成品补充组件和响应式细节，不得恢复旧版蓝绿粗边、超大标题或圆角卡片堆叠风格。

### 1.3 设计参数

- 设计变化：7/10。允许明显不对称、图片跨栏、全宽内容带和自然留白，但不追求难以使用的实验性。
- 动效强度：5/10。使用有目的的入场、视差、图像揭示和弹窗过渡，不使用炫技型滚动劫持。
- 信息密度：4/10。首屏清晰克制，长内容通过分类、图集、时间线和分层详情承载。

## 3. 全站视觉原则

### 3.1 图片先于容器

- 首页、课程、创作空间、校园合作、学员成长、咨询和走进科瑞特都必须有与内容直接相关的高质量图片。
- 大图优先使用通栏、跨栏、自然裁切、软边渐隐、纸张叠层、图文穿插或局部蒙版，不默认塞进圆角框。
- 图片与纯色之间使用雾化渐变、曝光过渡、纸张纹理、半透明色场或图像本身的留白连接，避免突然切换成大面积纯色。
- 真实课程、教师、学校、证书、奖项、学员与竞赛成果必须来自手册或已授权媒体。生成图只用于概念场景、抽象媒介、课程主题插图和暂不涉及真实身份的装饰。
- 生成图在后台和素材清单中保留来源与生成提示，不对访客显示内部来源标签。

### 3.2 卡片与圆角规则

- 卡片只用于确实独立、可点击、可选择或需要浮层层级的内容。
- 课程分类、成长历程、合作案例和品牌介绍优先使用分栏、图集、时间线、连续信息带、编辑式目录和留白分组。
- 禁止连续出现三张等宽等高圆角卡片。
- 禁止图片外层套圆角框、框内再套文字框、文字框再套按钮的多层容器。
- 图片本身默认不加粗黑描边；必要的圆角控制在 8-12px，按钮可使用轻微圆角或胶囊形，但全站需统一。

### 3.3 色彩与材质

- 以手册靛蓝与品牌 Logo 橙红建立品牌识别，白色使用略带冷感的非纯白。
- 不继续使用大面积荧光绿与纯黑描边作为主要风格。
- 同一页面只保留一个主强调色，Logo 橙红可作为小面积标记色。
- 背景依靠图片、材质、浅层次色差和留白形成深度，不用随机渐变或通用 AI 紫色光晕。
- 全站公开页面先采用一致的浅色主题，深色只在 AI 创作工具内部因功能需要出现，不能在公开长页面中反复明暗翻转。

### 3.4 字体与标题

- 公开页面使用具有现代中文显示品质的无衬线字体组合，不把超大字号当作唯一视觉重点。
- 首页 H1 桌面端建议 52-64px，最多两行；其他页面 H1 建议 44-56px，最多两行。
- 区块标题桌面端建议 32-44px，手机端 28-36px。
- 中文标题必须设置合理行宽和断行点，禁止第二行只剩 1-2 个字。
- 首屏副文案控制在约 20-36 个中文字，主要行动无需滚动即可看到。
- 英文眉题不再每个区块重复使用；公开中文页面以中文层级为主，必要时最多每三个区块使用一次短英文标识。

### 3.5 页面高度与响应式

- 首屏不是固定死的 `100vh` 海报，也不能把标题、按钮或图片底部裁在下一屏。
- 桌面端以 1366x768、1440x900、1920x1080 三组宽高核验首屏，导航、主标题、核心图片、主要行动必须形成完整画面。
- 手机端以 390px 宽核验，图文改为单列，标题不得超过三行，按钮不得断行，图片焦点不能丢失。
- 不为了“塞进一屏”缩小到难以阅读。长页面允许自然滚动，但每个主要区块的开头和结束要有完整节奏，不出现当前截图中的半截内容。
- 桌面导航高度控制在 64-72px，单行显示；空间不足时优先精简次要入口，移动端使用清晰的菜单。

## 7. 动效策略：React Bits 优先

### 7.1 来源优先级

1. 首选 [React Bits 官方组件库](https://reactbits.dev/get-started/index) 中与当前信息目标匹配的免费组件源码；按项目现有 React 技术栈复制、裁剪和适配，不套用默认皮肤。
2. React Bits 没有合适方案，或其依赖/性能成本不合理时，使用项目现有 CSS、Web Animations API 或既有动效能力实现等价的轻量效果。
3. MotionSites 降为灵感与案例参考，不再作为动效代码的首选来源；任何外部成品仍需先展示链接、使用位置和性能成本后再采用。

### 7.2 适用位置

- 导航进入与背景透明度变化：帮助导航和首屏影像融合。
- 首屏采用一次性的图片显现与文字序列入场，500-800ms 内完成，不反复播放。
- 课程目录、学习路径、学员作品与合作案例只在首次进入视口时分组揭示；避免每个小元素分别飞入。
- 项目或作品画廊可谨慎评估局部图像过渡，但文字、证书、Logo 和二维码不得参与会损害识别的扭曲动画。
- 登录、注册、首次使用提示与合作方式弹窗使用 300-500ms 的短距离淡入/缩放；按钮反馈控制在 100-150ms。

### 7.3 接入规则

- 每页最多一个主视觉动效，其余只做操作反馈和必要的状态连续性。
- 接入前记录组件名称、官方链接、依赖、许可声明、本地修改、移动端退化方式和性能结果；优先只动画 `transform` 与 `opacity`。
- React Bits 官方仓库当前采用 MIT + Commons Clause：允许作为网站或产品的一部分使用和修改，需保留许可声明，不得销售、再许可或重新分发组件本身。不得擅自使用未获授权的 Pro 内容。
- 所有非必要动效支持 `prefers-reduced-motion`；内容在 JavaScript 或动效失败时默认可见。
- 禁止滚动劫持、持续晃动、无意义视差、跟随光标特效、多个跑马灯和装饰性循环动画；普通内容页不引入重型 WebGL。
- 在 1366×768、1440×900、1920×1080 和 390px 宽度下验证构图，并在目标手机与桌面设备上检查帧率、滚动稳定性和输入响应。
